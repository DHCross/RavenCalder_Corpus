# The Symbolic Spectrum Table (SST)

The SST is the Woven Map's primary classification instrument. Every symbolic resonance is logged and categorized.

## Classification Categories

### WB — Within Bounds

Clear, direct recognition. The subject confirms the mirror accurately reflects their experience.

### ABE — At Boundary Edge

Partial, inverted, or mis-toned recognition:

- **Inverted:** Tension registers as release (or vice versa).
- **Shifted:** Right theme, wrong domain.
- **Delayed:** Recognition comes after the ping window.

### OSR — Outside Symbolic Range

Null data. No recognition despite clear geometry. Valid, valuable data that prevents false positives.

## Integration

The SST integrates with the Balance Meter (tracking which channels produce WB vs. OSR) and the Validation dataset (providing empirical grounding for accuracy claims).
