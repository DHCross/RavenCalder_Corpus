# Chart Types

The Woven Map works with multiple chart types, each serving specific diagnostic purposes.

## Primary Chart Types

### Natal Chart
The foundation. Baseline symbolic vocabulary, typological profiling, core pattern identification.

### Transit Chart
Current planetary positions overlaid on natal. Daily ping identification, timing analysis, Hook Stack construction.

### Progressed Chart
Symbolic evolution over time. Developmental patterns, life phase transitions, long-cycle analysis.

### Synastry Chart
Overlay of two natal charts. Relational diagnostics, echo pattern mapping, compatibility analysis.

### Composite Chart
Mathematical midpoint of two charts. Relationship entity analysis, shared purpose identification.

## Specialized Types

- **Relocation Chart** — Natal chart adjusted for new location.
- **Solar Return** — Annual birthday-to-birthday analysis.
- **Lunar Return** — Monthly emotional cycle tracking.
- **Triwheel** — Three-chart overlay for complex timing analysis.
