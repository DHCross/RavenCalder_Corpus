# Symbolic Navigation

## Navigation Principles

### Field-First Orientation
Navigation always begins with FIELD — raw geometry — before moving to MAP and VOICE.

### Tension-Driven Routing
1. Hard aspects between personal and outer planets
2. Angular placements
3. Anaretic degrees (29°)
4. Anchor planet configurations

### Loop Awareness
Pressure doesn't unfold linearly. The framework tracks recursive loops, retrograde signatures, and threshold returns.

## Navigation Instruments

- **Hook Stack** — Identifies daily hot spots.
- **Seismograph** — Measures magnitude, valence, and volatility.
- **Vector Map** — Tracks containment and release patterns.

## Relocation Handling

- Houses and angles move to the new location.
- Natal typology and planetary configurations remain fixed.
- Transit interpretations adapt to relocated houses.
