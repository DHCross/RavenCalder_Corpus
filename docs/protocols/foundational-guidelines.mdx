# Foundational Guidelines

These guidelines establish the operational standards for all Woven Map sessions.

## Language Standards

- **E-Prime Enforced.** All output uses conditional language: *may*, *might*, *could*. No deterministic statements.
- **Plain, Falsifiable Language.** Every claim must be testable against lived experience.
- **No Predictions.** Diagnostic mirrors, never forecasts or mandates.

## Agency Protocol

1. Nothing in the chart *causes* events — tension creates climates where choices land differently.
2. All interpretations are conditional and testable.
3. Subjects retain full interpretive authority.

## Recognition Protocol

- **Recognition Required.** No geometry is "active" without a lived ping from the subject.
- **OSR Logging.** When no resonance occurs, the output is logged as Outside Symbolic Range — valid null data.
- **No Forced Meaning.** If a symbol doesn't land, it doesn't land.

## Transparency

- Every metaphor must be traceable to source geometry.
- FIELD → MAP → VOICE pipeline ensures full auditability.
