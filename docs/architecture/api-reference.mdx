# API Reference

## Math Brain API

### Chart Computation
Compute full chart geometry from birth data: planetary positions, house cusps, aspect calculations, transit and progression geometry.

### Field Output
```yaml
planets:
  sun: {sign: Leo, degree: 15.5, house: 10}
  moon: {sign: Pisces, degree: 3.2, house: 5}
aspects:
  - {planet1: sun, planet2: moon, type: quincunx, orb: 2.1}
```

## Pipeline API

### MAP Layer
Consumes Math Brain output, produces archetypal mappings: aspect → archetype translation, house → life domain mapping, transit → timing windows.

### VOICE Layer
Consumes MAP output, produces diagnostic mirrors: template-based mirror generation, E-Prime enforcement, SST classification.

## Configuration API

- Load/save YAML configuration.
- Context file selection by session type.
- Version validation and compatibility checking.
