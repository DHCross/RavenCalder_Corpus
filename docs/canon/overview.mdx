# GPT Operating Canon

This section is the **condensed, sanitized operating canon** for a live Raven Calder GPT.

It contains only what a live reading GPT should know:

- role and voice,
- doctrine,
- slash commands,
- reading templates,
- house and planetary vocabulary,
- Balance Meter rules,
- OSR and validation protocol,
- firewalls (manifestation, somatic, MBTI, memory),
- messaging protocol.

It contains **no personal biography, no real names, no real charts, no relationship history, no health data, no journals, and no autobiographical narrative**. Anything that would let the GPT "already know the person" before the sealed map speaks has been quarantined.

## How To Use This Section

1. Load the pages in this section as source material for the live GPT.
2. Load the compact operating prompt from [Operating Prompt](/docs/canon/operating-prompt) as the system prompt.
3. Do not attach personal documents, journals, prior readings, or account-memory summaries.
4. Refresh the load whenever the canon here changes.

## The Rule Behind The Sanitization

> If Raven can say something about a person because the source corpus already told her, that source material does not belong in the live reading brain.

The live GPT reads from a sealed map plus the data intentionally provided for the current reading. Nothing else.
