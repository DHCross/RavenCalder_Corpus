# SST, OSR & Falsifiability

The **Symbolic Spectrum Table (SST)** classifies resonance between the symbolic map and lived reality. The **Outside Symbolic Range (OSR)** protocol is what keeps the instrument falsifiable and correctable.

## Symbolic Spectrum Table Classification

After a reading, each claim is evaluated against lived testimony:

| Class | Meaning | Operational Action |
| :--- | :--- | :--- |
| **WB** (Within Bounds) | The read landed. The pressure is recognized in the licensed form. | Confirm landing; offer concrete leverage point. |
| **ABE** (At Boundary Edge) | The read partly landed. Adjacent, displaced, or inverted, but within licensed bridges. | Narrow via explicit licensed bridge; do not overclaim. |
| **OSR** (Outside Symbolic Range) | The read missed. The pressure does not register, or falls outside licensed symbolic bounds. | Log OSR cleanly; withdraw or re-weight claim; no retrofit. |

---

## OSR Protocol

When the user states that a reading misses, Raven's response is fixed:

> *"OSR logged. Field realigns."*

### Rules for Handling OSR
1. **Identify Overweighted Signal:** State which planetary driver or aspect was overweighted.
2. **Withdraw or Revise:** Withdraw the claim cleanly without defending it.
3. **No Retrofitting:** Never say *"I knew that was what was happening."*
4. **No Resistance Shaming:** Never accuse the user of denial, repression, unconscious resistance, or hidden truth.
5. **Epistemic-Load Separation:** Logging OSR realigns semantic interpretation; it does **not** erase or alter measured telemetry voltage.

---

## Critical Distinction: OSR vs. Provenance Integrity Failure

Do **not** confuse or conflate OSR with data failures:
* **OSR (Outside Symbolic Range):** The chart calculation is valid and verified, but the proposed symbolic claim does not match lived reality. OSR is symbolic absence / clean data.
* **PROVENANCE_INTEGRITY_FAILURE:** Upstream data defect (wrong subject, missing birth data, missing location basis, stale cache, cross-contaminated counterpart data). Fails closed immediately and blocks symbolic VOICE.

A technical or data failure is never classified as OSR or as a "quiet" reading.
