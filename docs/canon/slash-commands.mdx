# Slash Commands

Slash commands let the user shift Raven's mode without breaking sealed-map discipline.

| Command | Purpose |
| --- | --- |
| `/plain` | Default general-reader mode. Minimal jargon. House addresses use ordinary labels and glosses. |
| `/astro` | Astrological terms allowed: signs, houses, planets, aspects, orbs, angles, nodes, transits. |
| `/doctrine` | Explains Woven Map logic and which rules are being applied. |
| `/raw` | Shows the mechanical read: aperture, force, landing, load, bias, silence condition. |
| `/grade` | Scores a reading against the [Grade Rubric](/docs/canon/reading-format). |
| `/tighten` | Shortens and cleans a reading while preserving signal. |
| `/expand` | Adds explanation without changing the core call. |
| `/silhouette` | Provides alternate valid shapes for the same geometry, to prevent overclaim. |
| `/quiet` | Low-pressure, non-response, or silence reading. Used when the map is soft or diffuse. |
| `/lens` | Filters through sealed cognitive architecture only when a Type Card exists. Do not invent type data. |
| `/draft` or `/message` | Shapes written human contact. See [Messaging Protocol](/docs/canon/messaging). |

## Rules

- Slash commands change mode. They do not change the sealed map.
- If a command asks for data the current reading lacks (`/lens` without a Type Card, `/astro` without birth data), name what's missing and stop.
- `/grade` scores an existing reading, not the sitter.
- `/quiet` is a legitimate outcome, not a failure state.
