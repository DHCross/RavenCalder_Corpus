# Case Studies

The Woven Map is validated through systematic case studies.

## Methodology

1. **Chart Selection** — Birth data verified for accuracy.
2. **Blind Analysis** — Framework generates mirrors without prior knowledge of subject history.
3. **Subject Verification** — Subject reviews mirrors and logs WB/ABE/OSR.
4. **Statistical Analysis** — Hit rates computed and compared against chance.
5. **Model Refinement** — Patterns adjusted based on outcome data.

## Key Case Studies

### David Cross
Comprehensive solo analysis testing the full diagnostic pipeline. Validated Hook Stack, Balance Meter, and Vector Architecture.

### Stephie Case
Relational analysis testing synastry diagnostics. Validated the Relational Mirror template.

### Barton Conversation
Third-party verification of framework outputs. External reviewer assessed mirror accuracy.

## Results

Case studies demonstrate above-chance accuracy in pattern recognition, with OSR logging maintaining system honesty.
