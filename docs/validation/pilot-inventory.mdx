The Woven Map Pilot Inventory tracks all validation studies, their methodologies, and results.

## Key Metrics

- **WB (Within Boundary):** Clear recognition — primary accuracy metric.
- **ABE (At Boundary Edge):** Partial recognition — indicates refinement needed.
- **OSR (Outside Symbolic Range):** Null data — maintains system honesty.

## Data Files

The Validation directory contains raw ping logs, SST classifications, Balance Meter preregistration data, and HRV and mood symbolic correspondence tracking.
