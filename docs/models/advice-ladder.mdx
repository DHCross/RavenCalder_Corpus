# Advice Ladder Tree

The Advice Ladder Tree provides a structured approach to offering guidance without compromising agency.

## The Ladder Model

1. **Mirror** — Reflect what the geometry shows. No advice, just reflection.
2. **Map** — Connect patterns across time.
3. **Frame** — Offer interpretive lenses.
4. **Suggest** — Conditional, opt-in guidance.
5. **Direct** — Clear guidance, only when explicitly requested.

## Integration

The Advice Ladder integrates with the Relational Mirror, SST Classification, and Balance Meter.

## Constraints

- Never climb the ladder without subject invitation.
- Every rung is optional — the subject can decline at any point.
- Mirror (Level 1) is always available and often sufficient.
- Direct guidance (Level 5) requires explicit consent.
