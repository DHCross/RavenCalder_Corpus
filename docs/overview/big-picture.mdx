# The Big Picture

The Woven Map is not prophecy. It is a mirror — a way of holding pressure so it can be seen, tested, and released. Each reading is a dialogue between geometry and recognition, never a verdict.

## The Map Is Not the Land

The symbols are not commands. What matters is whether the mirror speaks to lived experience. The Woven Map holds the tension between structure and choice — agency never leaves the subject's hands.

## Core Instruments

- **Hook Stack** — Identifies where tension is loudest in the chart.
- **SST (Symbolic Spectrum Table)** — Classifies every resonance as WB, ABE, or OSR.
- **Balance Meter** — Converts raw pressure into narrative climate across four channels.
- **Vector Architecture** — Describes how structural tension is held, suppressed, or released.

## Ethical Framework

- **No External APIs**: Offline operation only.
- **Agency Preservation**: No deterministic statements.
- **Falsifiability**: All output testable against experience.
- **Clear Mirror Principle**: Diagnostic reflection, not prediction.
