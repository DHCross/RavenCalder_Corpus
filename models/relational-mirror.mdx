# Relational Mirror

The Relational Mirror extends the Woven Map framework to interpersonal dynamics. It maps how two symbolic landscapes interact, echo, and create shared climates.

## Core Concepts

### Bidirectional Echoes

When two charts interact, both are active. Neither is passive. The framework tracks:
- **Echo Patterns** — Where one person's transit activates the other's natal point, and vice versa.
- **Resonance Loops** — Reciprocal activations that amplify shared themes.
- **Friction Points** — Where geometries clash, creating tension in the relational field.

### Tier-Specific Gates

Relational analysis uses gated depth levels:

1. **Surface Gate** — Outer planet contacts and synastry highlights.
2. **Mid Gate** — House overlays, element balances, modality dynamics.
3. **Deep Gate** — Composite chart, progressed synastry, karmic signatures.

## Mirror Output

The Relational Mirror produces:
- **Climate Description** — The shared symbolic weather.
- **Echo Map** — Bidirectional activation patterns.
- **Friction Analysis** — Where tension lives in the relationship.
- **Support Pathways** — Where geometry offers stability and flow.

## Constraints

- Relational mirrors are diagnostic, never prescriptive.
- Both subjects retain full agency.
- The framework describes dynamics, never assigns blame.
