# The Symbolic Resonance Protocol

*Version 3*

The Symbolic Resonance Protocol governs how the Woven Map matches symbolic patterns to lived experience. It defines the conditions under which a symbolic pattern is considered "active" and how resonance is verified.

## Resonance Conditions

For a symbolic pattern to be considered resonant:

1. **Geometric Presence** — The pattern must exist in the chart geometry (FIELD).
2. **Archetypal Coherence** — The pattern must map to a recognizable archetypal motif (MAP).
3. **Lived Recognition** — The subject must confirm the pattern resonates with experience (VOICE verification).

## Resonance Types

### Direct Resonance
The pattern maps cleanly: geometry → archetype → experience. Logged as WB (Within Boundary).

### Inverted Resonance
The pattern manifests as its opposite: tension registers as release, or vice versa. Logged as ABE (At Boundary Edge).

### Delayed Resonance
The pattern doesn't register immediately but activates days or weeks later. Still logged as WB, with timestamp.

### Null Resonance
The pattern generates no recognition despite clear geometry. Logged as OSR — valid absence, not failure.

## Protocol Rules

- Resonance is never assumed, always verified.
- OSR results are as valuable as WB — they calibrate the system.
- Subjects are the final authority on their experience.
- No pattern is "real" without lived ping.
