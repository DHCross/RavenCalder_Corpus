# The Symbolic Spectrum Table (SST)

The SST is the Woven Map's primary classification instrument. Every symbolic resonance is logged and categorized, creating a transparent, auditable record of framework accuracy.

## Classification Categories

### WB — Within Boundary
Clear, direct recognition. The subject confirms the mirror accurately reflects their experience. This is the framework's primary accuracy metric.

### ABE — At Boundary Edge
Partial, inverted, or mis-toned recognition. The pattern is present but manifests differently than expected:
- **Inverted:** Tension registers as release (or vice versa).
- **Shifted:** The theme is right but the domain is wrong.
- **Delayed:** Recognition comes later than the ping window.

### OSR — Outside Symbolic Range
Null data. The pattern generates no recognition despite clear geometry. This is valid, valuable data — it calibrates the system and prevents false positives.

## Template Usage

The SST Template Guide (v3) provides structured formats for:
- Daily ping logging
- Session output classification
- Longitudinal pattern tracking
- Statistical aggregation for model refinement

## Integration

The SST integrates with the Balance Meter (tracking which channels produce WB vs. OSR) and the Validation dataset (providing empirical grounding for accuracy claims).
