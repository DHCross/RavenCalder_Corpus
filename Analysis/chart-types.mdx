# Chart Types

The Woven Map framework works with multiple chart types, each serving specific diagnostic purposes.

## Primary Chart Types

### Natal Chart
The foundation. Represents the symbolic landscape at birth. Used for:
- Typological profiling
- Core pattern identification
- Baseline symbolic vocabulary

### Transit Chart
Current planetary positions overlaid on the natal chart. Used for:
- Daily ping identification
- Timing analysis
- Hook Stack construction

### Progressed Chart
Symbolic evolution of the natal chart over time. Used for:
- Developmental pattern tracking
- Life phase transitions
- Long-cycle analysis

### Synastry Chart
Overlay of two natal charts. Used for:
- Relational diagnostics
- Echo pattern mapping
- Compatibility analysis

### Composite Chart
Mathematical midpoint of two charts. Used for:
- Relationship entity analysis
- Shared purpose identification
- Couple-level pattern recognition

## Specialized Types

- **Relocation Chart** — Natal chart adjusted for a new location.
- **Solar Return** — Annual chart for birthday-to-birthday analysis.
- **Lunar Return** — Monthly chart for emotional cycle tracking.
- **Triwheel** — Three-chart overlay for complex timing analysis.
