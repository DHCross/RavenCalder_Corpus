# Case Studies

The Woven Map framework is validated through systematic case studies. Each case tests the framework's ability to produce accurate, recognizable mirrors from chart geometry.

## Methodology

Each case study follows a standard protocol:

1. **Chart Selection** — Birth data verified for accuracy.
2. **Blind Analysis** — Framework generates mirrors without prior knowledge of subject history.
3. **Subject Verification** — Subject reviews mirrors and logs WB/ABE/OSR.
4. **Statistical Analysis** — Hit rates computed and compared against chance.
5. **Model Refinement** — Patterns adjusted based on outcome data.

## Key Case Studies

### David Cross
Comprehensive solo analysis testing the full diagnostic pipeline. Validated the Hook Stack, Balance Meter, and Vector Architecture against documented life history.

### Stephie Case
Relational analysis testing synastry diagnostics. Validated the Relational Mirror template and bidirectional echo tracking.

### Barton Conversation

## Results

Case studies demonstrate above-chance accuracy in pattern recognition, with OSR logging maintaining system honesty. Full datasets available in the Validation directory.
