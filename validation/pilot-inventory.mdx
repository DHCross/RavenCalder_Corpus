# Pilot Inventory & Validation Data

The Woven Map Pilot Inventory tracks all validation studies, their methodologies, and results. This dataset provides the empirical foundation for the framework's accuracy claims.

## Key Metrics

- **WB (Within Boundary):** Clear recognition — the framework's primary accuracy metric.
- **ABE (At Boundary Edge):** Partial recognition — indicates need for refinement.
- **OSR (Outside Symbolic Range):** Null data — maintains system honesty.

## Data Files

The Validation directory contains:
- Raw ping logs and SST classifications.
- Balance Meter preregistration data.
- HRV and mood symbolic correspondence tracking.
- 2025 Ping Log with dynamic tracking data.

## Research Access

All validation data is available for independent review. The framework welcomes external audit and replication studies.
