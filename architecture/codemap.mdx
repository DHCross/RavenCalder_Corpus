# Codemap & Guardrails

The codemap provides a navigational overview of the WovenWebApp codebase, and the guardrails define safety and quality constraints.

## Guardrails

### Data Safety
- No external API calls — all computation is local.
- Subject data never leaves the local environment.
- Session outputs are archived locally only.

### Quality Constraints
- All Math Brain output must be deterministic.
- Poetic Brain output must be traceable to FIELD geometry.
- E-Prime enforcement at VOICE layer.
- SST logging for all diagnostic output.

### Version Control
- Current version: 9.3.25
- Files older than 7.20.25 are deprecated.
- All version changes tracked in configuration files.
